# VisionGuard AI documentation

Start here. All of this is based on the **current repository**, not an unimplemented spec.

**Honesty:** Default demo uses mock weather, synthetic satellite rasters, OpenCV/rule-based “AI”, and prototype alerts. Live OpenWeather and local YOLO are optional. There is no bundled trained U-Net, no GEE, no real SMS.
